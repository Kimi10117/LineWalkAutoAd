# 《LINE 散步趣》原生 Android 自動看廣告助手 (LineWalkAutoAd)

專為 **Android 11 (API 30+)** 打造的《LINE 散步趣》(LINE WALK) 原生 Kotlin 自動看廣告 App。

## 核心特色
1. **免每次授權錄影權限**：採用 Android 11+ `AccessibilityService.takeScreenshot()` 無感截圖 API，開啟一次無障礙服務即可永久使用。
2. **手機端「即時框選取樣」 (`TemplateCropOverlay`)**：
   - 無需連電腦截圖裁切！直接在遊戲中點擊懸浮窗的 **`[✂️ 取樣]`**，用手指拉框圈選**「集滿的水瓶」**、**「移動距離獎勵」**或**「特殊廣告 X 圖示」**，即可直接存入本機範本庫。
3. **三層混合辨識引擎**：
   - **第一層 (`NodeInspector`)**：毫秒級掃描原生無障礙節點樹 (`AccessibilityNodeInfo`) 的 `close / skip` 按鈕。
   - **第二層 (`OcrRecognizer`)**：內建 **Google ML Kit 離線中英文 OCR v2**，自動辨識遊戲與廣告中的 `看廣告`、`觀看影片`、`略過`、`跳過`、`關閉`、`已獲得獎勵`、`確認` 及倒數秒數。
   - **第三層 (`TemplateMatcher`)**：雙階段粗精搜 ZNCC + RGB 色彩相似度局部比對（精準區分「滿水瓶」與「空水瓶」），並內建免樣本幾何角落 `X` 偵測器。
4. **防迷路與防假 X 黑名單 (`AdCloserHandler`)**：
   - 若誤觸「假 X」跳轉至 Google Play 商店或外部瀏覽器，自動觸發系統 `BACK` 返回鍵，並將該假 X 座標加入單次黑名單避免重複誤觸。
   - 所有點擊均附帶隨機座標偏移 ($\pm 5\text{ px}$) 與隨機按壓時長 ($65\text{ ms} \sim 138\text{ ms}$)。

## 如何編譯與安裝至手機

### 方法一：使用 Android Studio（推薦）
1. 打開 **Android Studio**，選擇 **Open**，開啟本專案目錄：
   `C:\Users\kimic\.gemini\antigravity\scratch\LineWalkAutoAd`
2. 等待 Gradle Sync 完成（會自動下載對應的 Gradle 8.6 與 ML Kit 離線中文套件）。
3. 將你的 Android 11+ 手機開啟「開發人員選項 -> USB 偵錯」連接電腦，點擊頂部綠色 **Run (`▶`)** 即可安裝至手機；或點擊選單 **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** 產出 APK 檔案傳至手機安裝。

## 首次使用教學（3 分鐘上手）

1. **開啟兩項必要權限**：
   - 打開「散步趣自動看廣告助手」App。
   - 點擊 **`[1. 開啟無障礙服務]`**，在系統無障礙設定中找到 **「散步趣自動看廣告無障礙服務」** 並開啟。
   - 點擊 **`[2. 授權懸浮窗權限]`**，允許顯示於其他應用程式上層。
   *(註：若 Android 13+ 系統提示「受限制的設定」，請至「系統設定 -> 應用程式 -> 散步趣自動看廣告助手 -> 右上角選單 -> 允許受限制的設定」即可開啟無障礙服務。)*
2. **啟動懸浮窗並取樣「滿水瓶」圖示**：
   - 點擊綠色按鈕 **`[🚀 啟動懸浮控制窗並打開《LINE 散步趣》]`**。
   - 當遊戲畫面中有**已裝滿的水瓶**時，點擊左側懸浮窗上的 **`[✂️ 取樣]`**。
   - 畫面會凍結，請用手指在畫面上**框選出單一顆「滿水瓶」圖示**，確認上方分類為 `1. 步數滿水瓶圖示 (優先)`，點擊 **`[💾 儲存框選範本]`**。
3. **開始全自動掛機看廣告**：
   - 點擊懸浮窗上的 **`[▶ 開始]`**，助手就會自動循環執行：
     **找滿水瓶並點擊 ➡️ 自動點「看廣告領取」 ➡️ 等待廣告倒數並自動點 `>>` / `X` 關閉 ➡️ 點擊「確認」領取金幣 ➡️ 繼續點下一瓶水瓶！**
